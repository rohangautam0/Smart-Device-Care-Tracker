Smart Device Care & Repair Tracker

A Python-based project to manage electronic device repair records and track repair progress.

Features

- Manage device repair records
- Track repair status
- View total repairs
- Count received, in-progress, ready-for-pickup, and delivered devices
- Store repair data in JSON format

Technologies Used

- Python
- JSON
- Git
- GitHub

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the command:

python app.py

Project Objective

To simplify repair record management and help track the status of electronic devices.
